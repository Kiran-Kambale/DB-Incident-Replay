# Contributing

Suggestions and bug reports are welcome.

1. Reproduce the issue with a local PostgreSQL database and synthetic data.
2. Include OS, Python/PostgreSQL versions, reproduction steps, expected behavior and actual behavior.
3. Redact credentials, hostnames, customer identifiers, and sensitive SQL literals.
4. For code changes, describe how the change was tested and whether it changes database permissions or queries.
5. Do not propose automatic remediation against a database without explicit safeguards and user approval.

This project is a learning prototype. Contributions should preserve its local-first safety posture and distinguish observed evidence from hypotheses.
